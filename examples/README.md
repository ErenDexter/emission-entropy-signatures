# Example photos

Two photos of one sprayed Bangladeshi 2-Taka banknote (2023 series), taken with an iPhone 11 under a 365 nm UV lamp.

| File | Role |
|---|---|
| `IMG_3705.HEIC` | Enrolment photo (first angle) |
| `IMG_3850.HEIC` | Test photo of the same banknote, taken from another angle and under different lighting |

With the trained model, the test photo matches the enrolled banknote with 407 agreeing droplets (inliers); the accept threshold is 20. See "Quick start" in the main README.

The full set of 276 photos (138 banknotes) is available from the corresponding author on reasonable request.
